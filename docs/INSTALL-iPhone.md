# Install Aurora on your iPhone (Windows PC, no App Store)

You need: your iPhone, its USB cable, a Windows PC, and a free Apple ID.

## 1. One-time PC setup
1. Install **iTunes** and **iCloud** from Apple's website, **not** the Microsoft Store versions:
   - iTunes: https://www.apple.com/itunes/download/win64
   - iCloud: use the "iCloud (non-Microsoft Store)" link on https://sideloadly.io
2. Install **Sideloadly** from https://sideloadly.io.
3. Plug in the iPhone, unlock it and tap **Trust This Computer**. iTunes should show the phone.

## 2. Turn on Developer Mode (iPhone)
Settings → Privacy & Security → **Developer Mode** → on, then restart the phone when asked. (The option appears after Sideloadly has tried to install an app once, so you can come back to this step.)

## 3. Install Aurora
1. Download **Aurora-iOS-x.y.z.ipa** from https://github.com/UndeadBossGames/Aurora-iOS/releases/latest.
2. Open Sideloadly, drag the .ipa onto it, pick your iPhone, type your Apple ID, and press **Start**. Sideloadly asks for your Apple ID password itself; it signs the app for your phone only.
3. On the iPhone: Settings → General → **VPN & Device Management** → your Apple ID → **Trust**.
4. Open Aurora. 🎉

## 4. Every 7 days (free Apple ID)
Apps signed with a free Apple ID stop opening after 7 days. Plug the phone in and press **Start** in Sideloadly again with the same .ipa. Your profiles and music stay. (Sideloadly's "auto-refresh" option can do this for you over Wi-Fi.)

## Getting music onto the phone
- **iTunes File Sharing**: iTunes → the phone icon → **File Sharing** → **Aurora** → **Add File…** (or drag songs in). Use your Aurora downloads folder on the PC (Music\Aurora).
- **Files app**: in Aurora, Library → **Add music** → **Choose from Files**.
- New files are added automatically when you open Aurora, or tap **Add music → Check for new files**.

## Updating
Install the newer .ipa with Sideloadly the same way. Your data is kept.
